
# ☀️ HavaAz — Weather Forecast Website

HavaAz is a modern and responsive weather forecast website for cities and districts of Azerbaijan.

The website provides real-time weather data and a 7-day forecast using the **Open-Meteo API** and **AJAX (XMLHttpRequest)** without reloading the page.

## 🚀 Features

- 🌍 Weather forecasts for 74 locations in Azerbaijan
- 🔍 Search and select cities or districts
- 🌡️ Current temperature and feels-like temperature
- 💧 Humidity and wind speed
- 🌧️ Precipitation probability
- 📅 7-day weather forecast
- ☀️ Dynamic weather icons
- 📱 Fully responsive design
- ⚡ AJAX requests without page reload

## 🛠️ Technologies

- HTML5
- CSS3
- Vanilla JavaScript
- AJAX (XMLHttpRequest)
- Open-Meteo API

## ▶️ Getting Started

1. Clone or download the repository.
2. Open the project folder in Visual Studio Code.
3. Run `index.html` using the Live Server extension.
4. Select a city to view its weather forecast.

## 🌐 API

Weather data is provided by [Open-Meteo](https://open-meteo.com/).

No API key is required for non-commercial use.
